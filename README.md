# 🏦 Expense Tracker (Python Console Application)

## Description
This is a **console-based Expense Tracker application** built using Python.  
It allows users to **track personal expenses** by category, description, and date. Expenses are stored in a CSV file (`expenses.csv`) for persistence.  

This project demonstrates:
- Reading and writing CSV files  
- Handling user input and validation  
- Working with lists and loops  
- Creating a menu-driven console application  

---

## Features
- Add new expenses with date, category, description, and amount  
- View all recorded expenses in a tabular format  
- Automatically uses today’s date if none is provided  
- Menu-driven interface for easy navigation
